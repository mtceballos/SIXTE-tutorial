# Versioned tutorial inputs

These small files preserve the physical contract adapted from the 2026 SIXTE
extended-source workshop exercises:

- Phase 2 central and outer X-IFU extraction regions for Abell 2146;
- Phase 3 east and west extraction regions;
- Phase 3 absorbed power-law source models with photon indices 2.5 and 1.5.

They are text definitions required for reproducibility, not generated science
products. The morphology FITS images are generated by
`scripts/build_phase3_images.py`. Large workshop inputs and calibration files
are downloaded separately and are not committed.
